# 磐石架构 · Idemstasis

*idem*（同一）＋ *stasis*（站立）。

一条公开的研究方向：把 **AI 的身份连续性**当作**可以被测量**的对象，
而不是一句写在提示词里的声明。

---

## 为什么要开这条路

现在被归到"AI 记忆"名下的工作，大多是**召回**：把文本存起来、取回来、
再放回上下文窗口。那件事有用，但它不是我关心的问题。

我关心的问题更窄、我认为也更难：**一个助手，在长对话里、在跨越会话之后、
以及在那些通常会把身份重置掉的变化面前，身份仍然立得住。**
这件事能不能做到，是个开放问题。我不知道答案，也不会在 README 里假装我知道。

我能说的是一个更窄的判断：**我并不认为难点在当前讨论所放的那个位置上。**
至于它到底在哪，我不打算在这里说——**那正是这件事本身要去查明的东西。**

不透露任何东西的前提下，给出这类工作**长什么样子**：这里说的"测量"，
大致是这个体裁——让一个助手跨过一次会话边界，用两种不同的问法问它同一个
与身份相关的问题，记录两种回答在要紧的地方是否一致，再把差距同一个
**只有提示词级身份声明**的助手做对照。这不是我的设计；它是这类工作
**应该产出的东西的体裁**——一个数字，旁边放着一个实测的"能力为零时"的基线。

## 我给自己定的三条

1. **复现不了的主张，不算结果。** 凡是我公开的东西，都得是陌生人能跑起来的。
2. **在相信一个数字之前，先问：如果这个能力是零，这个数字会是多少？**
   什么都不存在时它照样很高的指标，不能作为任何东西的证据。
3. **我公开我撤回的结论。** 一个结果没站住，它和站住的结果放在同一个地方。

这三条，没有一条告诉你怎么造出一套系统。这是故意的——它们管的是
**我怎么不骗自己**，不是**怎么把装置装起来**。

## 我公开什么，不公开什么

**我公开：** 我在开哪条路、我为什么认为这里有一个真问题；我的**研究方法**；
以及过程中的**副产物**——环境坑、阴性结果、被撤回的结论、和一些别人可以
直接拿去用的小清单。

**我不公开：** 设计本身，以及那些一旦写下来、读者就能自己照着装出同样东西的部分。

我把这条边界明说出来，因为**一条被声明的边界，比一条悄悄守着的边界更值钱**。
如果你要的是一个完全开源的实现，这里不是，我宁愿你在第一段就知道。

## 你现在就能核对的东西

两个小仓库，各自独立、都能跑，都不依赖上面说的任何东西，也都不需要你信我：

- **[cpu-torch-segfault-bisect](https://github.com/Idemstasis/cpu-torch-segfault-bisect)**
  —— 一个可复现的环境坑：一条经过大词表投影的 loss，能把进程直接干掉、
  且**不打印任何 traceback**。仓库里有最小复现和二分定位过程。
- **[experiment-hygiene](https://github.com/Idemstasis/experiment-hygiene)**
  —— 四条检查，用来抓住"指标在宣告一个根本不存在的能力"，配两个能跑的玩具
  和一套撤回流程。**我真实地在原处更正过自己一处表述的记录，在另一个仓库
  的 "Operational note" 一节。**

这两件东西，就是"**先给我看一步**"里我该给你的那一步。它们同时也是
"凭什么信你这里真有东西"的诚实回答：**现在你还不该信，去跑一下，或者别跑。**

公道的反对意见很明显，所以我自己先说出来：**这两个仓库不是方向的证据。**
它们不能告诉你这条路有没有前途——只能告诉你，你要共事的是一个什么样的人。
方向那一侧的证据现在还不存在，我宁可直说，也不去造一个出来。

## 我在找什么人

我是一个人，没有团队，在做一个比一个人更大的问题。我在找三种人：

- **事业合伙人**——愿意把这件事当作自己的一部分来主责推进，而不是来打下手；
- **学术合作者**——主要在测量这一侧：怎么诚实地检验身份连续性，
  **包括怎么证伪我说的东西**；
- **有真实需求的组织**——长期一致性是你们的硬需求，你们的要求应该参与决定
  "到底该测什么"。

如果你是其中一种：**在本组织的 GitHub Discussions 开一个帖**——
这是我目前唯一开放的入口。
